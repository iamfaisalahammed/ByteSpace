# ByteSpace New

A modern and responsive landing page built from the ByteSpace New Figma design.

## Live Demo



## Features

- Responsive design
- Modern UI implementation
- Reusable React components
- Clean and maintainable code
- Fast performance with Vite

## Technologies Used

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)

## Installation

```bash
git clone https://github.com/your-username/bytespace-new.git
cd bytespace-new
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
